# Project Context

## Project

Vertical Slice 01

## Goal

Build a small playable vertical slice of the 2D RPG.

## Current Product Scope

The first delivery contains:

- exploration;
- dialogue;
- choices;
- mission state;
- combat;
- party;
- save/load.

## Explicitly Out of Scope

- inventory;
- items;
- shops;
- money;
- complex map;
- generic NPCs;
- audio;
- advanced combat abilities;
- Haki;
- Akuma no Mi mechanics.

## Development Principle

Build the smallest complete playable experience.

Avoid implementing future systems prematurely.
